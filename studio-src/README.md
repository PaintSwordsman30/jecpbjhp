# studio-src

Copies of the scripts written during the milestone 4–7 audit of the Roblox Studio place "GUARDIAN TEST".

The place itself is the source of truth: the game is not built from this folder. Each file here mirrors one script in Studio, with the Studio path as the folder path and `.luau` added to the name. At the time of each commit the file was byte-identical to the script in Studio (same length and checksum).

Scripts that already existed and were only edited are not copied here. Their edits are listed in the milestone reports under `docs/milestone-reports/`.
